# 0001 Stack: Django + React on PostgreSQL

- Status: decided, 4 Nov 2026 (Sidharth)
- Decision: Python 3.13, Django 5.2 LTS + Django REST Framework, PostgreSQL 16, Celery + Redis, React + TypeScript (Vite).
- Why: mature and well known, keeps the team in Python (familiar from Frappe/ERPNext), real transactions and NUMERIC money types.
- Rejected: NestJS + Prisma (same architecture, less built in).

# 0006 AI makes drafts, never postings

- Status: decided as a guardrail, 3 Nov 2026
- Decision: AI features (bill capture, matching, ask-your-data, anomaly alerts, forecasting) may create Draft documents or suggestions only. A person with permission submits. Figures always come from reports; the assistant has the user's permissions and read-only tools; every suggestion is audit-logged; each feature has an on/off switch and a spend cap per tenant.
